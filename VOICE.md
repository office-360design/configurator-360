# Vocea 360Configurator în limba română

## Public și obiectiv

Scriem pentru producători, distribuitori, echipe de vânzări și clienții care trebuie să înțeleagă un produs configurabil. Copy-ul trebuie să explice repede ce poate face utilizatorul și ce rezultat obține.

## Concept: Clar

**Caracteristici:** direct, concret, ușor de parcurs

**Ce înseamnă:** Folosim propoziții scurte și verbe cunoscute. Numim produsul, acțiunea și rezultatul.

**Da**
- „Configurează panourile. Estimează producția și consumul.”
- „Alege forma, dimensiunile și învelitoarea acoperișului.”

**Nu**
- „Simulează ziua energetică.”
- „Explorează infrastructura spațială de produs.”

## Concept: Tehnic, dar accesibil

**Caracteristici:** precis, explicat, fără jargon inutil

**Ce înseamnă:** Păstrăm termenii recunoscuți de specialiști, precum CAD, CRM, ERP și PVGIS. La prima apariție, explicăm BOM ca „listă de materiale”.

**Da**
- „Exportă lista de materiale în format CSV.”
- „Folosește date PVGIS pentru locația exactă.”

**Nu**
- „Rezoluție CAD și continuitate comercială.”
- „BOM-ul continuă în aceeași stare operațională.”

## Concept: Orientat spre rezultat

**Caracteristici:** util, comercial, verificabil

**Ce înseamnă:** Descriem ce obține utilizatorul, nu doar mecanismul intern al platformei.

**Da**
- „Configurația aprobată produce lista de materiale și datele necesare ofertării.”
- „Modelul semnalează suprapunerile înainte de calcul.”

**Nu**
- „Un strat operațional pentru produse configurabile.”
- „O experiență de înaltă fidelitate.”

## Adresare și mecanică

- Folosim persoana a II-a singular: „alegi”, „configurezi”, „produsul tău”.
- Folosim sentence case pentru titluri și butoane.
- Evităm liniile de pauză în copy-ul publicat. Preferăm punct, virgulă sau două propoziții.
- Butoanele numesc rezultatul: „Vezi configuratoarele”, „Solicită evaluarea proiectului”.
- Mesajele de eroare spun ce s-a întâmplat și ce poate face utilizatorul în continuare.

## Glosar preferat

| Folosim | Evităm |
|---|---|
| configurator 3D | sistem spațial |
| configurație | stare de produs / stare comercială |
| sistem fotovoltaic | acoperiș solar / sistem solar |
| panouri fotovoltaice | panouri solare, când este vorba despre electricitate |
| poziția soarelui | timp solar |
| analiză solară pe baza adresei | context solar după adresă |
| listă de materiale (BOM) | BOM fără explicație pentru publicul general |
| tip de implementare | traseu de implementare |
| ce include proiectul | scopul proiectului |
| modele și resurse 3D | active 3D |
| platformă de comerț electronic / e-commerce | commerce |
| cerere / solicitare comercială | lead, în copy-ul pentru publicul general |
| montaj autoportant | montaj independent |
| rulou textil / rulou ZIP motorizat | screen, dacă denumirea comercială nu impune termenul |
| vedere explodată | analiză explodată |
| variantă structurală | preset de solicitare |

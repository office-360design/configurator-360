# PBR texture sources

These 1K JPEG maps are derived from Poly Haven assets released under CC0:

- `fence-wood-*`: [Wood Table 001](https://polyhaven.com/a/wood_table_001), lightly exposure-balanced for the bright website stage
- `fence-metal-*`: [Blue Metal Plate](https://polyhaven.com/a/blue_metal_plate)
- `roof-metal-*`: [Box Profile Metal Sheet](https://polyhaven.com/a/box_profile_metal_sheet)
- `roof-granule-*`: [Clean Asphalt](https://polyhaven.com/a/clean_asphalt)
- `roof-slate-*`: [Roof Slates 03](https://polyhaven.com/a/roof_slates_03)

Only the maps needed for browser rendering are included. Poly Haven attribution is
not required by CC0, but the sources are recorded here for provenance.

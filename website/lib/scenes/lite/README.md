# Website-owned product previews

Source baseline: repository commit `05329b7`. All edits are confined to `website/`.

Cardbox catalogue update: all nine styles are now exposed (superseding the earlier three-style scope below). `cardbox-catalog.json` is generated read-only from original definitions, translated labels and SVG icons. Selecting a style applies its original dimensions, closures and default features; the UI includes compatible closure choices and TFT/AFT/AFA paper presets. The renderer uses cardbox's original NoToneMapping, light settings and camera angle instead of the other previews' warm filmic setup. Ground/background rendering remains website-specific. The live app JS and local source were SHA-256 identical when checked on 2026-09-24.

- Chair imports production geometry and GeometryLibrary. `scripts/bake-chair-materials.mjs` runs the original material providers ahead of time, preserving presets and color/normal/roughness maps. Oak is downsampled to 512px; other woods are 512px and fabrics 128px. Visitors do not run the procedural generators.
- Bookshelf contains native module, door, shelf and connector functions from `bookshelf-configurator/js/app.js`. Natural, mahogany and wenge PNGs are imported directly from its assets. Native shelf slots, hardware and door-open states are now exposed. Startup, editor controls and authentication remain excluded. Review snapshot parity on source updates.
- Cardbox uses the final native inside/outside surface pipeline (`makeColoredSurfaceMesh`, `applyFeaturesAndSurfaceColours`), board/paper definitions, closure visuals and hinge transformations. It does not use the superseded `makeSurfaceMesh` path. Original outer edge lines are included, white outer paper retains the natural inner liner, and the preview starts closed. Source-parity tests compare extracted functions with the repository. Three structures are exposed; full board editing, artwork, pricing and editor tools remain in the full app. The source itself represents top opening as whole-panel inspection motion, not individual flap simulation.
- Tiles imports native layout, stone appearance and house geometry. Native viewer functions render pieces, cut fragments, curbs and houses with the same seeded bump texture. House exclusions affect installed-piece counts and net paved area. Quantities exclude spare allowance.

`scripts/sync-lite-native-builders.mjs` prints an apply_patch-compatible update for coupled cardbox and paving renderer functions. Review before applying; it never modifies original applications. Bookshelf remains a separately reviewed snapshot. The website owns lighting, camera and bounded controls, so these are source-backed previews, not pixel-identical full-app embeds.

`runtime.js` dynamically imports only the selected builder. The four additions share one leased renderer; switching products disposes the outgoing model. Leaving all previews disposes the renderer after a short grace period. Controls and finite camera damping invalidate rendering; no continuous idle render loop runs. Mobile, reduced-motion and Save-Data visitors activate explicitly. A server-rendered vector poster and full-app link remain available without WebGL.

The six established previews retain their existing stage and behaviour. New product detail pages do not mount that stage. On the homepage it stops drawing when its own sections are out of view. This rollout isolates the additions without refactoring the production configurators or changing the established preview engines.

Validate with `npm run release:static`, then `node --test tests/lite-products.test.mjs`. Inspect desktop, touch and reduced-motion behaviour in a real browser. Unit tests cover geometry bounds, closure/volume combinations, production paving parity and generated SEO on all twelve new pages.

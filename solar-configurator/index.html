Demo security & caching

Google Solar proxy not tested yet.

Paid requests run only through the Google Cloud Run service. The API key is never shipped to the browser. The service requires the demo access code, issues a 2-hour signed session, applies transactional per-IP/global daily limits in Firestore, and caches Google results in Cloud Storage.

Building Insights is cached for 7 days. Data Layers metadata is reused while its URLs are valid. Downloaded hourly-shade, DSM and building-mask GeoTIFFs are cached for up to 30 days, matching Google's documented retention window.

Optional detailed roof & shade data: Google Maps Platform Solar API. Hourly shade uses standard time (no DST); the configurator converts Romania summer time before sampling it.
